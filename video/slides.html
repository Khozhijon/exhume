requirements.md

EARS acceptance criteria

### Requirement 2: MacPaint Decoder

4. WHEN decoding the bitmap, THE SYSTEM SHALL
   apply PackBits row by row ...

6. IF the compressed input is exhausted
   before 51 840 bytes are produced,
   THEN THE SYSTEM SHALL fill remaining
   pixels with white (0) and add a warning.

### Requirement 8: Damaged Input

2. WHEN decoding any prefix of a valid
   encoded file, THE SYSTEM SHALL return
   either a Specimen or throw ExhumeError;
   it SHALL NOT hang.

design.md

numbered correctness properties

### Property 1: Format round-trip
For any valid model m, decode(encode(m))
produces a payload that deep-equals m.

### Property 3: Annotation honesty
For any file produced by encode, the
top-level annotations cover every byte
index exactly once: no index appears in
two annotations, none is absent.
Validates: Requirements 9.3, 9.6

### Property 8: Lotus formula round-trip
For any generated formula tree: compile,
decompile, compile again is stable.
